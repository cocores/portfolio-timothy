The Problem

Annotating UIs shouldn't require a Figma license

During review cycles, PMs and designers constantly need to mark up screenshots — flag spacing issues, annotate interaction areas, add callouts for stakeholders. The existing workflow meant opening Figma, importing an image, adding annotations manually, and exporting. Too many steps for a quick async handoff.

I wanted a tool that lives in the browser, takes a screenshot, and lets you annotate in under 60 seconds.

The insight: The gap wasn't design capability — it was friction. A lightweight browser tool with the right four primitives covers 90% of annotation use cases without the overhead of full design software.

What I Built

Four tools. One tab.

The Hot Spot Tool is a React app with four annotation modes, each solving a distinct part of the review workflow.

📐

Measurements

Draw precise measurement overlays on any uploaded screenshot — ideal for spacing reviews and developer handoffs.

📍

Hotspots

Pin numbered hotspots to specific UI regions with attached notes — great for documenting interaction areas and flagging issues.

🖼

Infographics

Layer visual callouts and highlight zones over screenshots for stakeholder presentations and async walkthroughs.

✏️

Callouts

Add labeled arrows and text callouts to draw attention to specific elements — fast markup without leaving the browser.

Why I Built It

PMs who build move faster

This project started as a personal tool for my own review process. I kept reaching for Figma or Loom for things that should take 30 seconds. Building it in React let me ship exactly what I needed — and nothing more.

  • No account or install required — runs entirely in the browser
  • Upload any image and start annotating immediately
  • Export annotated screenshots for async review or Jira tickets
  • Built with React + Vite — fast, lightweight, no backend

Still actively developing

Dogfooding it in my own workflow at B&H. Next up: shareable annotation exports and a saved sessions layer.
